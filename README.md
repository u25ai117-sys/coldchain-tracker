# Cold Chain Vaccine and Medicine Logistics Tracker

A database-driven system that tracks vaccine and medicine batches from
manufacturer to health facility, monitors temperature in storage and
transit, and automatically raises alerts when safe limits are breached.

Course: Database Management Systems (AI203), SVNIT Surat

## Tech stack
- MySQL 8
- Python (FastAPI, Uvicorn, Jinja2)
- HTML, Bootstrap, Chart.js

## Folder structure
- sql/          database scripts (schema, triggers, views, queries)
- app/          FastAPI application
- docs/         report, ER diagram, slides
- screenshots/  UI screenshots
- data/         sample data and sensor simulator
